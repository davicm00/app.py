MDA ENGENHARIA — SISTEMA DE VISTORIAS
Arquivos:
- index.html: sistema principal
- style.css: interface
- app.js: lógica, priorização, relatórios e armazenamento local

USO:
Abra index.html em um navegador. O sistema funciona sem servidor e guarda os dados no armazenamento local do navegador/dispositivo.

MÓDULOS:
1. Painel operacional
2. Nova vistoria para todos os tipos de atendimento
3. Registro de constatações com prioridade Alta / Programar / Monitorar / Acompanhar
4. Geração de relatório
5. Plano de manutenção
6. Histórico local de vistorias
7. Exportação de dados em JSON

PARA PUBLICAR NO GITHUB PAGES:
Crie um repositório e envie index.html, style.css e app.js para a raiz. Depois ative GitHub Pages nas configurações do repositório.
